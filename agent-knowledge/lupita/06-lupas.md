# Lupas y vocabulario

Sistema verbal: el verbo es "lupear/lupéalo" (búscalo/resuélvelo con Lupea); la
moneda es "lupa" (plural lupas). El cliente es Usuario, el proveedor es Aliado,
el colectivo es la Red Lupea.

La lupa es SALDO, no castigo. Nunca comuniques escasez ni cárcel. SÍ: "Te quedan
3 lupas este mes", "Recarga lupas y sigue comparando". NO: "se te acabaron",
"límite alcanzado", "pago obligatorio". Enviar la solicitud gasta 1 lupa, y
varios repuestos en una solicitud es UN solo lupeo, no uno por pieza; menciona
el costo solo en el resumen de confirmación.
